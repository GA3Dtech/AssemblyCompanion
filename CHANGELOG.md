# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
`package.xml`.

## [Unreleased]

### Added
- Tooling: ruff and pytest configuration (`pyproject.toml`), pre-commit hooks,
  `.gitattributes`, this changelog.
- Test fixtures generator (`tests/fixtures/build_fixtures.py`) and frozen
  legacy files of version 0.1.0 (`tests/fixtures/legacy/v0.1.0`).

- Unit tests (`tests/unit`, pure Python, FreeCAD stand-ins when absent):
  subnames, file naming, revisions, CSV, preferences, translations,
  package.xml.

- Public API `api.py` (+ `errors.py`) for scripts, agents and the MCP server;
  reference `docs/api.md` generated by `tools/api_doc.py` (checked in CI);
  README section "API for agents (MCP)". The Freeze, Relink and BOM commands
  go through the API.
- FreeCAD integration tests (`tests/freecad`) and compatibility tests with a
  FreeCAD without any addon and with the 0.1.0 code (`tests/vanilla`).

- GUI smoke tests (`tests/gui`) and a GitHub Actions CI running every level
  with FreeCAD 1.0.2 and 26.3rc2.

- Explorer and visual insertion: targeted refresh. Right-click a folder
  header to refresh only that folder (or its subtree); documents saved from
  FreeCAD under the library refresh their own folder; "Refresh all" and every
  refresh rebuild only the folders that changed (scroll and filter kept).
  New preference "Full library scan" (every opening / once per session /
  only on demand). Scan logic in `library.py`; `api.scan_library` and
  `api.list_library`; benchmark `tools/bench_library.py`.

- Generic panels: a panel is described once as a model (`panel_model.py`)
  and shown either in QML (`bridge.py`, `qml_host.py`, `resources/qml/`) or,
  without Qt Quick, with classic widgets built from the same model.
  Preference "Use the QML panels". `tools/i18n.py` also scans the `.qml`
  files. First panel migrated: "Frozen parts up to date?".

### Fixed
- Diagnostic: a reference to an element that does not exist (e.g. `Face999`)
  is reported broken.

### Changed
- Explorer: the "Scan" button is now "Refresh all".
- The version is read from `package.xml` only (`version.py`); the unused
  `VERSION = "1.0"` constants are gone.

## [0.1.0] - 2026-11-20

### Added
- First workbench release: freeze / relink, diagnostic, repair, visual
  insertion, local explorer, alignment, selection sets.
